Gazette Web Interface

This project is a simple frontend interface for a news tip submission system.
It was built using HTML, CSS, and inline JavaScript to demonstrate the user interface for submitting information to a newsroom.

The interface allows users to navigate through pages, view content sections, and interact with buttons that simulate actions such as submitting tips or navigating categories.

Features
	•	Clean and simple layout
	•	Responsive interface design
	•	Navigation buttons with JavaScript actions
	•	Organized content sections
	•	Static frontend structure ready for backend integration

Technologies Used
	•	HTML5
	•	CSS3
	•	JavaScript (inline)

How to Run

Since this is a static project, you can run it directly in your browser.
	1.	Download or clone the repository.
	2.	Open index.html in your browser.

No server or installation is required.

Purpose

This repository focuses only on the frontend layout and interaction design.
The backend bot system used to process submissions is not included in this repository.
